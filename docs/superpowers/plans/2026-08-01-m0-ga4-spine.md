Tests that must exist and must have been seen failing first:
- 401 → `AnalyticsAuthError`, **and `http` called exactly once** (no retry).
- 403 → `AnalyticsPermissionError`, called once.
- 404 → `AnalyticsEmpty`, called once.
- 429 → retried; `Retry-After: 7` ⇒ `sleep` received `7.0`.
- 429 without `Retry-After` ⇒ exponential `base_delay * 2**attempt`.

- success on the 2nd attempt returns the body and does not sleep again.
- `CollectOutcome`: no errors + 0 rows ⇒ `ok`/0; errors + rows>0 ⇒ `partial`/1;
  errors + 0 rows ⇒ `failed`/2.
